# Установка на PocketBook

Проверенное устройство: PocketBook PB740-2, InkPad 3 Pro, горизонтальный экран 1872 × 1404. Для другой модели потребуется адаптация размеров и проверка InkView.

## Сборка и установка

1. Выполните `scripts/build-pocketbook.sh` из корня проекта, установив инструменты, перечисленные в README.
2. Подключите читалку как USB-накопитель.
3. Распакуйте полученный ZIP и скопируйте содержимое его `applications` в `applications` на читалке.
4. Безопасно извлеките накопитель, отключите USB и откройте «Приложения → PaperCalendar».

```text
applications/
  PaperCalendar.app
  paper-calendar/
    paper-calendar
    config.json
```

При обновлении **заменяйте бинарник `paper-calendar` и при необходимости launcher**. Сохраняйте свой `config.json`, `credentials.sh`, `LIVE_CALDAV` и каталог кэша: там находятся настройки, отметки и неотправленные изменения задач.

## Настоящий календарь

Без файла `LIVE_CALDAV` launcher запускает вымышленные данные. Для подключения аккаунта:

1. Укажите коллекции календарей в `applications/paper-calendar/config.json`.
2. Проверьте `timezone`, `font_path` и `font_family`. Для PB740-2 используется `/mnt/ext1/system/fonts/Sans_Regular.ttf` и семейство `PT Sans`.
3. Оставьте `web_enabled: false`, если веб-просмотр на устройстве не нужен.
4. Создайте в папке приложения `credentials.sh` со своими значениями:

   ```sh
   export CALDAV_USERNAME='your-user'
   export CALDAV_PASSWORD='your-app-password'
   ```

   Значения должны быть корректно заключены в кавычки POSIX shell. Не добавляйте этот файл в Git. Он содержит пароль в открытом виде и должен оставаться только на вашем устройстве.

5. Создайте пустой файл `LIVE_CALDAV` рядом с `config.json`.
6. Подключите читалку к Wi-Fi штатными средствами и перезапустите PaperCalendar.

При первом переходе с вымышленных данных используйте отдельный каталог кэша, например `"cache_dir": "cache-live"`, чтобы не показывать старые демонстрационные события.

## Управление

| Действие | Результат |
| --- | --- |
| Нажать день | Расписание выбранного дня справа |
| Физическая кнопка назад / вперёд | Предыдущий / следующий месяц |
| «Сегодня» | Текущий месяц и день |
| «Обновить» | Немедленная синхронизация |
| Нажать встречу со временем справа | Описание встречи |
| «Назад к списку» | Возврат из описания |
| Нажать задачу в правой панели | Выполнить или отменить выполнение |
| Нажать задачу в календарной сетке | Выбрать день, не меняя выполнение |
| Стрелки справа | Страницы соответствующего списка |
| Долгое касание в описании | Возврат к списку |
| Долгое касание вне описания | Выход из приложения |

Через 30 секунд без действий интерфейс возвращается к сегодняшнему дню. Справа отображаются задачи выбранного дня и задачи без даты. Выполненные задачи без даты скрываются через 30 секунд; задачи выбранного дня остаются справа, чтобы можно было отменить выполнение. В самой сетке галочки не переключаются.

Отправка статуса задачи начинается примерно через 3 секунды. Без сети очередь сохраняется на устройстве. Повторная попытка выполняется при следующей синхронизации или по кнопке «Обновить». Нижняя подпись сообщает об ожидающих отправки изменениях.

Названия событий в правом расписании переносятся до пяти строк. Высота записи и область нажатия увеличиваются вместе с текстом; более длинные названия заканчиваются многоточием, полный текст доступен в описании встречи.

## Экран и аккумулятор

Сетка месяца кэшируется в памяти: выбор дня, описание, страницы задач и галочки рисуются поверх готовой основы. Это уменьшает вычисления при взаимодействии. Кэш ограничен одним изображением и обновляется при изменении месяца, событий или шрифта. На исходном экране не планируется лишнее пробуждение только ради возврата к нему через 30 секунд; необходимые таймеры задач и синхронизации сохраняются.

- Автоматическая синхронизация по умолчанию раз в 12 часов (дважды в сутки).
- Срок следующей синхронизации сохраняется между запусками. В полночь дата и выбранный день меняются по локальному кэшу без подключения к сети; новый месяц при отсутствии его данных загружается отдельно.
- Изменения галочек отправляются одной пачкой через 30 секунд после последней отметки; до отправки они сохраняются в очереди на накопителе. Ручное обновление отправляет их сразу.
- Переход ко сну запрашивается через 3 секунды бездействия; возврат к сегодняшнему дню через 30 секунд сохраняется.
- Одинаковые данные не вызывают перерисовку.
- Обновляются только нужные прямоугольники; периодически выполняется полная очистка против накопления следов.
- При включённом `wifi_on_demand` Wi-Fi используется для синхронизации и выключается после неё.
- Подсветка временно гасится и восстанавливается при выходе.
- Приложение запрашивает сон после периода бездействия. Первый запрос ограничен минутой, последующие учитывают ближайшее обновление и таймеры интерфейса.

На зарядке и при недоступном сне служебная проверка выполняется не чаще раза в минуту, кроме ближайших таймеров интерфейса. При отказе сна повторные попытки замедляются до интервала 5 минут.

Поддержка сна и пробуждения зависит от прошивки. Время автономной работы не измерено.

## Диагностика

`launch.log` находится в папке приложения. В каталоге `cache_dir` сохраняется `power-status.json`: количество синхронизаций и обновлений экрана, запросы сна, состояние питания, `last_render_ms` и `last_paint_ms`.

Отметки хранятся в `completed-tasks.json`, неотправленные изменения — в `task-outbox.json`. Не удаляйте очередь, если хотите сохранить изменения, сделанные без сети.

Для удаления приложения удалите `applications/PaperCalendar.app` и `applications/paper-calendar`. Это удалит и локальные настройки с кэшем; при необходимости сначала сделайте их копию. Книги и настройки прошивки приложение не меняет.


Если под расписанием выбранного дня остаётся свободное место, оно заполняется событиями следующего дня. Заголовок «Завтра» (или «Следующий день» при просмотре другой даты) и ссылка «ещё» выбирают этот день. Нажатие на событие со временем открывает описание. Данные берутся из кэша, без отдельной синхронизации.
